# Jhon Wictor Dev Portfolio

Static portfolio website for Jhon Wictor Dev, built with HTML and CSS to showcase services, selected work, and contact entry points in a lightweight GitHub Pages-ready format.

## Live Site

https://yungwictor.github.io/wictor-dev-portfolio/

## Overview

- Hero section with positioning and call to action
- Selected work grid
- Service presentation
- Contact section for lead capture
- Fully static deployment with no build step

## Stack

- HTML
- CSS

## Project Files

- `index.html`
- `portfolio.css`
- `assets/`

## Local Preview

Open `index.html` in a browser to preview the site locally.

## Deployment

This project is published with GitHub Pages from the `main` branch.
